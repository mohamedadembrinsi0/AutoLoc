# AutoLoc

## Présentation

AutoLoc est une application de gestion de location de véhicules permettant de faciliter la réservation et la gestion des véhicules pour les clients et les agences.

## Acteurs

Le système AutoLoc comporte les acteurs suivants :

* **Client** : consulte les véhicules disponibles, recherche un véhicule et effectue une réservation.
* **Agent d'agence** : gère les locations et les véhicules de l'agence.
* **Responsable d'agence** : supervise l'activité de l'agence et gère les opérations de son agence.
* **Administrateur** : administre l'ensemble de la plateforme et gère les utilisateurs et les paramètres du système.

## Cas d'utilisation

### Client

* Consulter les véhicules disponibles
* Rechercher un véhicule
* Consulter les informations d'un véhicule
* Réserver un véhicule
* Consulter ses réservations
* Annuler une réservation

### Agent d'agence

* Ajouter un véhicule
* Modifier un véhicule
* Supprimer un véhicule
* Consulter les réservations
* Gérer les locations

### Responsable d'agence

* Consulter les activités de l'agence
* Superviser les agents
* Gérer les véhicules de l'agence
* Consulter les statistiques de l'agence

### Administrateur

* Gérer les utilisateurs
* Gérer les agences
* Superviser les véhicules
* Administrer la plateforme
